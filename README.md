# Weather App (Flask + OpenWeather API)

A simple weather web app built using Flask that shows real-time weather data and a 5-day forecast with a Chart.js graph.

---

## Features

- Search weather by city name  
- Real-time temperature, humidity, and weather conditions  
- 5-day forecast graph  
- Dynamic background based on weather  
- Rain animation for rainy weather  
- Loading indicator and error handling  
- Responsive UI  

---

## Tech Stack

- Frontend: HTML, CSS, JavaScript  
- Backend: Flask (Python)  
- API: OpenWeatherMap  
- Visualization: Chart.js
